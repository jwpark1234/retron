# retron

옛날 DOS 게임, 슈퍼패미컴(SFC), 게임보이 어드밴스(GBA) 게임을 브라우저에서 하는 웹 런처입니다. 여러 게임을 등록해 두고 라이브러리에서 골라 플레이합니다.

> 게임 파일은 이 저장소에 들어 있지 않습니다. 본인이 가진 게임 파일을 직접 등록해서 씁니다. 등록한 게임은 브라우저 저장소(OPFS)에 두고, 로그인하면 본인 구글 드라이브에만 올라갑니다. 다른 사용자와 공유되지 않습니다.

## 기능

- **라이브러리**: 등록한 게임을 그리드나 목록으로 봅니다. 썸네일은 게임 아이콘(.ico)이 있으면 그것을, 없으면 첫 실행 화면을 1:1로 잘라 씁니다.
- **게임 등록**: zip이나 ROM 파일을 고르거나 창에 끌어다 놓습니다.
  - **DOS**: 실행 파일이 있는 폴더를 C:로 씁니다. bin/cue나 iso가 있으면 D:(CD)로 연결합니다. CD 음악(레드북 오디오)도 재생됩니다.
  - **SFC**: .sfc, .smc, .fig, .swc / **GBA**: .gba
  - **zip**: zip 끝의 파일 목록을 읽고 파일마다 잘라서 스트리밍으로 풉니다. 수백 MB짜리, macOS·iOS에서 압축한 zip, 4GB가 넘는 zip(zip64)도 되고, 한글(CP949) 파일명도 읽습니다.
- **저장**
  - **게임 안 세이브**: 게임에서 저장하면 브라우저에 자동으로 보관됩니다.
  - **상태 저장/불러오기**: 게임마다 슬롯 4개를 씁니다.
  - **자동 저장**: 나가거나, 웹을 닫거나, 다른 앱으로 넘어갈 때 저장하고, 3분마다도 저장합니다.
- **화면 버튼**: Save·Load(슬롯 팝업을 엽니다), 빨리가기(눌러서 켜고 끕니다), 메뉴(☰).
  - 휴대폰: 조작 영역 윗줄 왼쪽에 Save·Load, 오른쪽에 빨리가기·메뉴
  - PC: 화면 아래 가운데에 네 버튼을 흐리게 띄웁니다
- **게임 중 메뉴(☰)**: 열면 게임이 멈춥니다.
  - 나가기(자동 저장), 화면 필터(선명, 부드럽게, CRT), 전체화면
  - 재시작(처음부터. 그 전 상태는 자동 저장 슬롯에 남깁니다), 스크린샷(정수배로 키운 PNG로 내려받기)
  - SFC·GBA: 빨리가기 배속(2×, 3×, 4×). RetroArch는 실행 중에 배속을 못 바꿔서, 지금 상태를 들고 에뮬레이터를 다시 띄웁니다
  - 휴대폰: 화면 방향(가로, 세로)
  - DOS 휴대폰: 세로 화면은 트랙패드 위치(왼쪽·오른쪽), 가로 화면은 방향 패드·키 버튼·트랙패드 순서, 키 버튼 고르기(전체 키보드에서). 마우스 감도
  - SFC·GBA: PC는 키보드 설정(기본 배치가 있고 기종마다 공통), 휴대폰은 가상패드 켜고 끄기
- **계정 메뉴**: 동기화 상태, 기기 저장 공간(쓰는 양 / 쓸 수 있는 양), 게임 업로드는 Wi-Fi에서만, 휴대폰 조작 공통 설정(방향 조작 원형·십자 패드, 버튼 크기, 버튼 투명도, 버튼 햅틱), 로그아웃
- **게임 설정(카드의 ⋯)**
  - 이름 변경
  - DOS: 실행 파일, 속도(cycles), 휴대폰 화면 키, 키 재배치(PC), 게임패드 버튼 배치
  - 세이브 백업: 게임 안 세이브와 상태 슬롯을 zip으로 내보내고 가져옵니다.
  - 정보: 기기 저장 공간, 추가한 날, 마지막 플레이
  - 게임 삭제
- **조작**
  - PC: DOS는 키보드와 마우스, SFC·GBA는 키보드(메뉴에서 바꿈)
  - 휴대폰 DOS: 방향 패드(방향키), 트랙패드(탭은 왼쪽 클릭, 길게 누르면 오른쪽 클릭), 키 버튼
    - 세로 화면: 윗줄 방향 패드·트랙패드, 아랫줄 키 버튼
    - 가로 화면: 화면 아래에 방향 패드, 키 버튼, 트랙패드 한 줄 (순서를 바꿀 수 있습니다)
  - 휴대폰 SFC·GBA: 가상패드. 십자 패드는 가운데를 X자로 나눠 누른 방향의 오각형이 밝아집니다
  - 게임패드: 꽂고 아무 버튼이나 누르면 바로 씁니다. DOS는 버튼을 키나 마우스 버튼으로, 스틱은 방향키나 마우스 커서로 보냅니다
  - 화면 확대(핀치 줌, 두 번 탭)는 막혀 있습니다

알려진 게임은 맞춤 설정을 씁니다(`src/platforms/dos/profiles.ts`). 지금은 창세기전2가 들어 있습니다.

## 실행

```bash
npm install
npm run dev
```

`npm run build`를 하면 `dist/`에 정적 파일이 만들어집니다.

### 구글 로그인과 드라이브 저장

Cloudflare Pages는 정적 파일 서빙만 합니다. 로그인하면 게임 파일, 세이브, 설정이 **각 사용자의 구글 드라이브** `retron` 폴더에 저장되고, 다른 기기에서 같은 계정으로 로그인하면 게임을 받아 이어서 할 수 있습니다. 앱은 `drive.file` 권한만 써서, 자기가 만든 파일 외의 드라이브 내용은 보지 못합니다.

```
내 드라이브/retron/
  games/{게임키}/   게임 파일 + manifest.json
  saves/{게임키}.zip 세이브 묶음 (게임 안 세이브, 상태 슬롯, SRAM)
  settings.json     볼륨, 화면 필터 등
```

- `.env`의 `VITE_GOOGLE_CLIENT_ID`: Google Cloud OAuth 클라이언트 ID (웹 애플리케이션). 승인된 JavaScript 원본에 사이트 주소를 넣어야 합니다.
- `npm run deploy`: 빌드한 뒤 Cloudflare Pages 프로젝트 `retron`에 배포합니다.

## 구성

| 영역 | 사용 기술 |
|---|---|
| UI | Preact + Vite |
| DOS | [js-dos 8](https://js-dos.com) `emulators` (DOSBox-X, Worker). js-dos 기본 UI는 쓰지 않고 화면, 소리, 입력을 직접 연결합니다 |
| SFC·GBA | [Nostalgist.js](https://nostalgist.js.org) 0.23 (RetroArch snes9x·mgba 코어, `public/retroarch/`에 둡니다). 자체 UI는 쓰지 않습니다 |
| 저장소 | OPFS (게임 파일, 세이브, 상태, 썸네일) |
| 로그인·저장 | Google Identity Services, Google Drive API (`drive.file`) |
| 서빙 | Cloudflare Pages (정적 파일만) |

```
src/
  library/      게임 목록, 가져오기(zip, bin/cue 변환), 상태 슬롯, 썸네일, OPFS
  platforms/
    dos/        js-dos 연결, 세이브 감시, 게임 프로필
    retro/      SFC·GBA (Nostalgist) 플레이어, 가상패드, 키 설정
  cloud/        구글 로그인, 드라이브 API, 게임 올리기/받기, 설정 동기화
  sync/         세이브 동기화
  player/       기종 공통 플레이 부품: 게임 메뉴, 화면 버튼, 방향 패드, 화면 방향, 일시정지·상태 저장 연결(bridge)
  screens/      라이브러리, 게임 설정, 첫 화면
  ui/           설정 값(prefs), 공용 부품, 아이콘, 햅틱, 확대 막기, 조작 버튼 크기·투명도(CSS 변수)
```

## 참고

- js-dos 8은 CD 오디오 트랙으로 raw BINARY만 재생합니다. 그래서 bin/cue는 등록할 때 `DATA.ISO`와 `TRACKnn.BIN`으로 나눠 둡니다.
- DOS 상태 저장은 DOSBox-X의 savestate(`hand_savestate`/`hand_loadstate` 이벤트)를 씁니다.
- DOS 빨리가기는 DOSBox-X Turbo(`hand_speedlock2` 이벤트)를 켜고 끕니다. 배속은 정할 수 없고 최대 속도입니다.
- DOS 재시작은 js-dos에 리셋이 없어서 에뮬레이터를 새로 띄웁니다.
- 메뉴를 열면 에뮬레이터를 멈춥니다. 멈춘 동안에는 상태 저장 명령이 처리되지 않아서, 저장·불러오기(나갈 때 자동 저장 포함) 동안만 잠깐 풀었다가 다시 멈춥니다 (`src/player/bridge.ts`).
- 버튼 햅틱: 안드로이드는 `navigator.vibrate`, 아이폰은 iOS 18부터 스위치 체크박스의 시스템 햅틱을 빌려 씁니다. 그보다 옛 iOS는 진동이 없습니다.
