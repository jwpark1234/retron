retron 개인정보처리방침

시행일 2026년 10월 16일

retron(retron.pages.dev)은 사용자가 가진 옛날 게임 파일을 브라우저에서 실행하는 웹 앱입니다. 이 문서는 retron이 어떤 정보를 어디에 두고 어떻게 쓰는지 설명합니다.

1. 받는 정보

  • 구글 계정 이메일 주소: 로그인한 계정을 화면에 보여 주고, 다시 열었을 때 같은 계정으로 이어 가기 위해 씁니다.
  • 구글 드라이브 접근 권한 (drive.file): retron이 직접 만든 파일만 보고 쓸 수 있는 권한입니다. 사용자의 다른 드라이브 파일은 볼 수 없습니다.

2. 정보를 두는 곳

  • 사용자 본인의 구글 드라이브: 등록한 게임 파일, 세이브, 설정을 드라이브의 retron 폴더에 저장합니다. 다른 기기에서 같은 계정으로 이어서 하기 위해서입니다.
  • 사용자의 브라우저: 게임 파일, 세이브, 설정, 로그인한 계정 이메일을 브라우저 저장소에 둡니다. 오프라인에서도 게임을 하기 위해서입니다.
  • 로그인 유지 쿠키: 드라이브 접근이 한 시간마다 끊기지 않도록, 구글이 준 갱신 토큰을 암호화해 사용자 브라우저의 쿠키에 둡니다. 이 쿠키는 retron 서버로만 보내지고 자바스크립트로 읽을 수 없습니다.

retron 운영자는 사용자의 게임 파일, 세이브, 설정, 드라이브 내용을 서버에 저장하지 않고 볼 수도 없습니다. retron 서버(Cloudflare Pages)는 앱 파일을 내려주고, 위 쿠키로 구글에 새 접근 토큰을 요청하는 일만 합니다.

3. 제3자 제공

개인정보를 판매하거나 제3자에게 제공하지 않습니다. 광고·분석 도구를 쓰지 않습니다. 서비스를 위해 다음 업체의 기능을 씁니다.

  • Google: 로그인, 구글 드라이브 저장
  • Cloudflare: 웹사이트 호스팅 (일반적인 접속 기록이 Cloudflare에 남을 수 있습니다)

4. 구글 사용자 데이터 사용

retron이 구글 API로 받은 정보의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 받은 정보는 위에 적은 기능에만 쓰고, 다른 목적으로 쓰거나 사람이 열어 보지 않습니다.

5. 삭제와 권한 철회

  • 앱의 계정 메뉴에서 로그아웃하면 로그인 유지 쿠키를 지우고 구글에 갱신 토큰 취소를 요청합니다.
  • 구글 계정 → 서드파티 앱 및 서비스에서 retron의 접근 권한을 언제든 철회할 수 있습니다.
  • 드라이브의 retron 폴더를 지우면 드라이브에 둔 게임·세이브·설정이 지워집니다.
  • 브라우저의 사이트 데이터를 지우면 기기에 둔 정보가 지워집니다.

6. 바뀔 때

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다.
