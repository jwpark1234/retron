# 그림 원본

- `icon-logo.html`: 아이콘(어두운 브라운관 화면 속 RETRON 로고, CRT 효과). 앱 로고(src/style.css의 `.logo`)와 같은 글꼴·같은 효과. 창을 정사각형으로 맞춰 `#round`(둥근 모서리)를 붙여 찍으면 `favicon.png`(128)·`icon-192.png`·`icon-512.png`, 그냥 찍으면 `apple-touch-icon.png`(180, iOS가 모서리를 깎는다)
- `landing-collage.html`: 첫 화면 배경(`public/landing-bg.jpg`). 고전 게임 장르 화면 여덟 가지를 직접 그려 CRT를 씌운 콜라주. 1920×1200으로 찍어 JPG(품질 72)로 저장

찍은 PNG는 꼭 열어서 그림이 보이는지 확인한다 (about:blank 페이지에서 file:// 이미지를 불러오면 깨진 그림이 찍힌다).
